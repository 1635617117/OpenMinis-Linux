## 安装与校验

- 包名 `com.openminis.linux`，启动器名称 **Minis Ultra**，架构 arm64-v8a。
- NDK r29 `29.0.14206865`；数据库版本 21（含 20↔21 双向迁移）。
- 从 2.0.22 及更早升级：首启会校验并（如有必要）修复捆绑的 aarch64 SDK 工具包；已装 2.0.23 的设备直接覆盖安装即可。
- 签名与校验说明见 `docs/SIGNING.md`。
